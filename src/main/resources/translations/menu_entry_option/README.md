# Menu option dictionaries

These files are the reviewed right-click menu options for each language.

They started from the BSD-2-Clause `iolave/osrs-translations` data (see `LICENSE`) and are
now maintained here. The Spanish file has been fully reviewed; the other languages are
initial copies and still need the same review.

The plugin bundles these files as a fallback and can download the latest copy from
`master` at runtime (`Menus -> Download menu translations`).

Format: `english text;translation`, one per line. Keep item, NPC, place, quest, skill and
spell names in English. Menu options are actions: translate them as Spanish infinitives.

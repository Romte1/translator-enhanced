# Menu entry rules

These texts are **right-click menu options**, not sentences and not labels.

## Translate the action

Use the Spanish infinitive:

- `Bank` → `Abrir banco`
- `Empty` → `Vaciar`
- `Empty Dish` → `Vaciar`
- `Net` → `Pescar con red`
- `View` → `Ver`
- `Exit` → `Salir`
- `Look-at` → `Mirar`
- `Deposit` → `Depositar`
- `Withdraw` → `Retirar`
- `Check` → `Comprobar`
- `Search` → `Buscar`
- `Take` → `Tomar`
- `Open` → `Abrir`
- `Close` → `Cerrar`
- `Use` → `Usar`
- `Climb-up` → `Subir`
- `Climb-down` → `Bajar`

Do not translate an action as a noun or an adjective. `Empty;Vacío` or
`Empty Dish;plato vacío` are wrong because “empty” is the action “vaciar”.

## Keep names in English

Never translate item, NPC, boss, place, quest, skill or spell names, even inside a phrase:

- `Buy: 1 x Nature rune` → `Comprar: 1 x Nature rune`
- `View Farming guide` → `Ver guía de Farming`
- `Take Spade` → `Tomar Spade`
- `Teleport to Waterbirth Island` → `Teletransportarse a Waterbirth Island`
- `Cast Ice Blast` → `Lanzar Ice Blast`

Generic room and interface names can be translated:

- `Chapel` → `Capilla`
- `Throne room` → `Sala del trono`
- `Formal garden` → `Jardín formal`

## Preserve the format

Copy colour tags, closing tags, numbers, quantities and parentheses exactly. Keep the
English key unchanged; only write the Spanish value.
